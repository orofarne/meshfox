TUI themes — real rendered colors

Every available TUI theme (built in, plus any in .meshfox/themes/tui/), exactly as meshfox theme-preview paints it in a terminal: the interface colors in an unfocused frame, and the editor's highlighted sample in a focused one, built from the theme's [ui] and [editor] palettes. Colors a theme leaves as ansi:… are shown here as the common xterm shade; your terminal shows its own.

Pick one and set [tui] theme = "…" in .meshfox/config.toml (local, next to the canvas) or ~/.meshfox/config.toml (global); each frame's bottom line shows the exact snippet. Regenerate this page with meshfox theme-preview --html -o FILE.
